Sample Store Created on Shopify to understand the flow of the Project 

Automation Testing Project using Python and Selenium 

##Features
  1. Created a Store on Shopify
  2. Published it with few products
  3. Tested the same website for below functionalities
     a) Opened the Website
     b) Searched for the Product
     c) Added the product to Cart
     d) Verified the cart if product is added or not

##Tools used
1. Python
2. Selenium
3. Shopify
4. AdNabu for Google Feed
5. AdNabu for Google Pixel
6. AdNabu for Facebook Pixel
